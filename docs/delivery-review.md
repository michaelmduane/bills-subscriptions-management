## Part 1: Squad Retro (Internal)

Run by the DRI (Michael) with the full squad. Honest, blameless, improvement-focused.

### Structure

**What we set out to do**
- Restate the Cycle 2 goal and committed scope
- What was the confidence level at kickoff vs. reality?

**What we actually delivered**
- Features shipped (or ready for pilot)
- What got cut or deferred?
- Metrics baseline established?

**Retro Questions**

| Question | Notes |
|----------|-------|
| **Did we actually deliver value?** | Did we ship something that moves recurring card GPV, or just infrastructure? Can a customer use this? |
| **Where did execution break down?** | Missed handoffs, unclear ownership, technical surprises, integration delays |
| **Where was decision-making unclear?** | Decisions that took too long, decisions made without the right people, decisions that got revisited |
| **Where did coordination overhead or dependencies slow us down?** | Knot integration timeline, cross-team dependencies, design ↔ eng handoff, review bottlenecks |
| **Was the work right-sized for 6 weeks?** | Too ambitious? Not ambitious enough? Should we have cut scope earlier? |
| **What would we do differently next cycle?** | Process changes, communication changes, tooling changes, scope approach |
